## 🏙️ ¿Qué es una Ciudad Inteligente?

Una Ciudad Inteligente es un sistema urbano donde la energía, la movilidad, el agua, los residuos y el alumbrado **no funcionan por separado**, sino conectados por:

| Pilar | ¿Qué hace? |
| :--- | :--- |
| 📡 **Sensores / IoT** | Miden aire, ruido, tráfico, temperatura, humedad y consumo |
| 📊 **Datos en tiempo real** | La información viaja y se analiza al momento |
| 🧠 **Decisiones inteligentes** | La ciudad ajusta luz, energía, rutas y servicios según lo que necesita |
| 👥 **Personas en el centro** | Todo busca mejorar la calidad de vida y cuidar el medio ambiente |

### 🔄 El ciclo de una ciudad inteligente

| Paso | Acción |
| :---: | :--- |
| **1. SENTIR** | Los sensores miden lo que pasa en la ciudad |
| **2. CONECTAR** | Los datos viajan por la red |
| **3. ENTENDER** | El sistema analiza patrones, fallas o desperdicio |
| **4. RESPONDER** | La ciudad ajusta, avisa, enciende, apaga o redistribuye |
| **5. APRENDER** | Con el tiempo, decide cada vez mejor |

## 🥽 ¿Qué es la Realidad Aumentada (RA)?

La Realidad Aumentada **superpone objetos digitales 3D sobre el mundo real** usando la cámara de tu celular o computadora.

- 👀 Ver la ciudad y cada escenario en **3D**
- 💡 Entender conceptos que en texto son difíciles de imaginar
- 🎮 Explicación más **interactiva y fácil de recordar**
- 📱 Sin instalar aplicaciones complicadas

## 🗺️ Los 10 escenarios de la ciudad

| # | Escenario | ¿Qué hace? |
| :---: | :--- | :--- |
| **00** | **Vista general** | Panorama urbano. Todo conectado por datos, sensores y decisiones en tiempo real |
| **01** | **Energía eólica** | El viento mueve aerogeneradores y se convierte en electricidad limpia, sin humo ni combustible |
| **02** | **Energía solar** | Paneles captan luz del sol y la convierten en electricidad sin moverse ni quemar combustible |
| **03** | **Edificio inteligente** | Regula luz, temperatura y consumo con sensores. Gasta solo lo que necesita |
| **04** | **Nodo energético** | Recibe, transforma, controla y distribuye electricidad. Equilibra producción y consumo |
| **05** | **Movilidad eléctrica** | Autos y autobuses eléctricos, puntos de carga, ciclovías y semáforos inteligentes |
| **06** | **Sensores IoT** | Miden aire, ruido, tráfico, temperatura y humedad para decidir mejor y más rápido |
| **07** | **Agua inteligente** | Controla almacenamiento, calidad y distribución. Detecta fugas y evita desperdicio |
| **08** | **Residuos inteligentes** | Contenedores separados por tipo con sensores de llenado. Recolección solo cuando se necesita |
| **09** | **Alumbrado inteligente** | LED que ajustan intensidad según luz natural y presencia de personas |
